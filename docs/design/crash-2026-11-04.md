## 根因

`PmgDesignerExtension.cpp:85-94`：

```cpp
void FPmgDesignerExtension::OnAssetClosed(UObject* Object, IAssetEditorInstance*)
{
    if (UWidgetBlueprint* WidgetBlueprint = Cast<UWidgetBlueprint>(Object))
    {
        if (IsValid(WidgetBlueprint) && VBoxs.Find(WidgetBlueprint)) // 89 行
        {
            VBoxs.Remove(WidgetBlueprint);
        }
    }
}
```

`VBoxs` 是 `TMap<TWeakObjectPtr<UWidgetBlueprint>, TWeakPtr<SVerticalBox>>`。构造函数用
`AssetEditorSubsystem->OnAssetClosedInEditor().AddRaw(this, &FPmgDesignerExtension::OnAssetClosed)` 注册了原始指针委托，但：

1. **析构函数没有注销该委托**——`RemoveAssetEditorSubsystemEvent()` 在 `~FPmgDesignerExtension()` 里被注释掉了（第 39 行）；
2. `Uninitialize()` 只把 `bIsDestroyed = true`、`VBoxs.Empty()`，没有注销委托；
3. 资产编辑器关闭时 `OnAssetClosed` 仍会被调用，此时 extension 可能已被销毁，`VBoxs` 成员是已释放内存 → `FindIndexByHash` 访问野指针崩溃。

反复用 MCP 打开/关闭 WBP 编辑器会累积悬空委托，因此这次恰好由关闭 `UI_TestLayer2` 触发。

## 修复（已落地）

修改 `Plugins/CORUI/Source/PuertsMixinGenerator/Private/PmgDesignerExtension.cpp`：

- 委托注册从构造函数移到 `Initialize()`，先 `RemoveAll(this)` 再 `AddRaw`，可安全重复初始化；
- `Uninitialize()` 与析构函数都调用 `RemoveAssetEditorSubsystemEvent()` 注销；
- `OnAssetClosed()` 增加 `if (bIsDestroyed) return;`，并把 `Find + Remove` 改为 `VBoxs.Remove(TWeakObjectPtr<UWidgetBlueprint>(WidgetBlueprint))`。

```cpp
FPmgDesignerExtension::~FPmgDesignerExtension()
{
    RemoveAssetEditorSubsystemEvent();   // 先注销，再释放
    VBoxs.Empty();
    bIsDestroyed = true;
    ...
}

void FPmgDesignerExtension::Uninitialize()
{
    RemoveAssetEditorSubsystemEvent();
    bIsDestroyed = true;
    VBoxs.Empty();
    FDesignerExtension::Uninitialize();
}

void FPmgDesignerExtension::OnAssetClosed(UObject* Object, IAssetEditorInstance*)
{
    if (bIsDestroyed) return;
    if (UWidgetBlueprint* WidgetBlueprint = Cast<UWidgetBlueprint>(Object))
    {
        VBoxs.Remove(TWeakObjectPtr<UWidgetBlueprint>(WidgetBlueprint));
    }
}
```

构建：`Build.bat CultivationOpenRealmEditor Win64 Development -Project=...` 成功（18.65s），
`UnrealEditor-PuertsMixinGenerator.dll` 已重新链接。

验证：重启编辑器后，依次打开并关闭 `UI_TestLayer2` → `UI_TestStack` → `UI_TestHubMain`
（共 4 次开关），编辑器保持存活，无新增 `Saved/Crashes` 目录。

## 原修复建议（存档）

```cpp
FPmgDesignerExtension::~FPmgDesignerExtension()
{
    RemoveAssetEditorSubsystemEvent();   // 先注销，再释放
    VBoxs.Empty();
    bIsDestroyed = true;
    ...
}

void FPmgDesignerExtension::Uninitialize()
{
    RemoveAssetEditorSubsystemEvent();   // designer 卸载时即注销
    bIsDestroyed = true;
    VBoxs.Empty();
    FDesignerExtension::Uninitialize();
}

void FPmgDesignerExtension::OnAssetClosed(UObject* Object, IAssetEditorInstance*)
{
    if (bIsDestroyed) return;            // 双保险
    if (UWidgetBlueprint* WidgetBlueprint = Cast<UWidgetBlueprint>(Object))
    {
        VBoxs.Remove(WidgetBlueprint);   // Remove 自身返回计数，避免 Find+Remove 两次查找
    }
}
```

更稳妥的做法是用 `AddSP`/`AddWeakLambda` 绑定到 `AsShared()` 的生命周期，或把 extension 改为 `TSharedFromThis`。

## 第二个崩溃：延迟初始化 lambda（2026-11-05 01:15）

- 报告：`Saved/Crashes/UECC-Windows-2AE10A35454C32BAF1AE1AB9DCA14BD4_0000`
- 错误：`Fatal error: Pure virtual function being called`（`WindowsPlatformMisc.cpp:867`）
- 调用栈：

```
FPmgDesignerExtension::GetOrCreateVBox()   PmgDesignerExtension.cpp:149
FPmgDesignerExtension::Initialize::<lambda_1>()   PmgDesignerExtension.cpp:69
FTimerUnifiedDelegate::Execute() / FTimerManager::Tick() / UWorld::Tick()
```

- 原因：`Initialize()` 用 `SetTimerForNextTick` 延迟初始化，lambda 裸捕获 `this` 与 `IUMGDesigner* InDesigner`。
  WBP 编辑器在下一 tick 前关闭时，designer 已销毁，lambda 仍在其上调用 `GetChildren()` 等虚函数 → 纯虚调用。
- 修复：
  - 增加 `TSharedPtr<uint8> LifeToken`，`Uninitialize` / 析构时 `Reset()`；
  - lambda 改为捕获 `TWeakPtr<uint8>`、`TWeakPtr<SWidget>`（designer）与 `TWeakObjectPtr<UWidgetBlueprint>`；
  - 执行前先 `Pin()` 校验，任一失效即返回；
  - 两处生命周期守卫（OnAssetClosed 委托 + 延迟 lambda）都落在 `PmgDesignerExtension` 同一类里。
- 构建：`Build.bat CultivationOpenRealmEditor ...` 成功。首次链接被 `CrashReportClientEditor.exe`
  占用 DLL，关闭崩溃上报进程后重新链接成功。
- 验证：重启编辑器后连续 3 次快速打开/关闭 WBP 编辑器（间隔 0.3s / 0.5s），再空闲 15 秒；
  编辑器保持存活，无新增 `Saved/Crashes` 目录。

## 复现

- 用 MCP 打开一个 WBP 资产编辑器，再关闭该窗口（重复多次）。
- 修复前：悬空委托累积，关闭时访问已释放的 extension → `VBoxs.Find` 崩溃。
- 修复后：已按该路径连续开关 4 次（`UI_TestLayer2` / `UI_TestStack` / `UI_TestHubMain`），编辑器存活，无新崩溃。
