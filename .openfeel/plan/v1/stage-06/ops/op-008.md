## 目标
修正 UMG 设计器左上角的 CORUI DrawCall 预估面板：补全渲染批次数模型，修掉崩溃与死代码，加节流与运行期开关。

## 实施步骤
- [x] **模型补全**：`FDrawCallState` 增加 Image/Text/Border/Box/Effect 分类计数、`RenderableCount`（元素数）、`ForceBreakCount`（强制断批）、`VisitedCount`（扫描控件数）、`UnknownLeafCount`（未识别叶节点）

- [x] **节流**：`LastRenderedSignature` 按 bp 记录面板内容签名，签名未变则跳过重绘/日志
- [x] **开关**：新增 `CORUI.DrawCallOverlay`（`TAutoConsoleVariable<bool>`，默认开）控制面板显隐
- [x] 编译验证（2026-11-15）
